Welcome to the python `recipes` library
=========================================

``recipes`` is a curated collection of python utilities. The goal of this
library is to provide a central source of generic utility functions (and
classes) for applications to use in order to minimize boilerplate and streamline
their code.  The library is structured according to
operations on the builtin python objects, extending their functionality.
